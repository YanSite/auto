# Синий час — Концепт сайта автосалона

Концепт команды «Есть что показать»: так может выглядеть онлайн автосалон.
Название, марка Vela, модели, цены, условия и адрес придуманы, это не сайт реального бизнеса. Сходство с реальными автомобилями случайно.

Прогулка по салону в синий час: тринадцать кадров от мокрого двора до места водителя, между ключевыми — короткие видео-проезды камеры.
Статический сайт без сборки: `index.html`, шрифты, изображения, видео. Открывается через любой веб-сервер.
Дизайн-пакет — `design-reference/avtosalon-siniy-chas/`.
